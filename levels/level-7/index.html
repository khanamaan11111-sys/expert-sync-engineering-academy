Rate Analysis & Costing

Build transparent unit rates from controlled material, labour and plant inputs — then connect those rates back to the BOQ.

0%
LESSON 01

Rate Analysis Fundamentals

LEARNING OBJECTIVE

Understand what a unit-rate build-up represents and how it connects to BOQ pricing.

Rate analysis develops a cost per unit of measured work from defined resources and assumptions. The exact method depends on contract, project and organizational practice. Keep every input traceable.

Unit Rate = Resource Costs + defined additions, all expressed on a consistent output basis.
💻 PRACTICAL COSTING TASK

Create a blank rate-analysis sheet with Item, Output Unit, Resource, Resource Unit, Consumption, Resource Rate, Cost and Source.

LESSON 02

Materials & Consumption

LEARNING OBJECTIVE

Calculate material consumption on a defined output basis.

Material quantities should come from drawings/specifications, approved mix/design information, standard/project rules or clearly identified training assumptions. Do not invent engineering design inputs.

Resource Cost = Consumption × Resource Rate.
💻 PRACTICAL COSTING TASK

Build a training material-cost table for one simple item using explicitly supplied assumptions.

LESSON 03

Labour Cost & Productivity

LEARNING OBJECTIVE

Convert labour inputs and productivity assumptions into unit costs.

Labour costing requires crew composition, wage/cost inputs, working time and productivity. Productivity varies with site conditions, method, skill, access and project context, so document the basis.

If a defined crew cost is C per day and verified output is Q units/day, labour cost per unit = C ÷ Q.
💻 PRACTICAL COSTING TASK

Create two productivity scenarios and compare their labour cost per unit.

LESSON 04

Plant & Equipment

LEARNING OBJECTIVE

Include plant/equipment cost on a consistent basis.

Plant costing may include hire/ownership-related inputs, operating time and output according to the exercise/project method. Avoid double counting resources already included elsewhere.

Plant Cost per Unit = Defined Plant Cost for Period ÷ Output for Same Period.
💻 PRACTICAL COSTING TASK

Prepare a simple equipment-cost build-up and state what is included/excluded.

LESSON 05

Wastage & Allowances

LEARNING OBJECTIVE

Apply only defined allowances and show them transparently.

Wastage or other allowances should not be hidden inside arbitrary multipliers. Use project/approved assumptions and show the basis. Different materials and activities may require different treatment.

Adjusted quantity = Base quantity × (1 + defined allowance rate), when that method is applicable.
💻 PRACTICAL COSTING TASK

Compare a base quantity with a clearly labelled training allowance and show the cost impact.

LESSON 06

Rate Build-Up

LEARNING OBJECTIVE

Combine resources into a transparent unit rate.

Bring material, labour, plant and other defined components together. Keep direct resource costs separate from later additions so reviewers can understand the build-up.

Direct Unit Cost = Material + Labour + Plant + other defined direct components.
💻 PRACTICAL COSTING TASK

Build one complete practice unit-rate analysis and reconcile its components.

LESSON 07

Overheads, Profit & Other Additions

LEARNING OBJECTIVE

Understand that additions depend on the pricing framework.

Overheads, profit, taxes, risk allowances and similar additions must follow the relevant commercial/project rules. They are not universal percentages. Training examples should label assumptions clearly.

Final pricing structure = Direct Cost + only the additions defined for the exercise/project.
💻 PRACTICAL COSTING TASK

Create a sensitivity table using clearly labelled hypothetical percentages rather than claiming market-standard values.

LESSON 08

Rate Library & Source Control

LEARNING OBJECTIVE

Create a reusable but controlled rate-input system.

A rate library should record resource description, unit, value, location/context, source, effective date and notes. Old values must not silently become current estimates.

Link rate-analysis cells to a controlled input table instead of repeatedly typing values.
💻 PRACTICAL COSTING TASK

Create a 15-resource training rate library with Source and Effective Date fields; use illustrative values only.

LESSON 09

Sensitivity & Cost Drivers

LEARNING OBJECTIVE

See how changes in inputs affect unit cost.

Sensitivity analysis helps identify which assumptions materially influence a rate. It does not predict future prices. Change one variable at a time or clearly define scenarios.

Test changes in a material rate, labour productivity and plant cost, then compare unit-rate impact.
💻 PRACTICAL COSTING TASK

Build Base, Scenario A and Scenario B for one item and explain the main cost driver.

LESSON 10

Level 7 Costing Project

LEARNING OBJECTIVE

Produce an auditable set of rate analyses linked to a BOQ.

Use your Level 6 BOQ and prepare several rate build-ups. Link controlled inputs, document assumptions, calculate unit rates and update the training estimate. Finish with QA and sensitivity checks.

Deliverable: rate library + at least five unit-rate analyses + updated BOQ + source register + assumptions + sensitivity note.
💻 PRACTICAL COSTING TASK

Complete five rate analyses and explain how each final rate is derived.
