PROJECT STAGE 01

Project Brief & Document Control

STAGE OBJECTIVE

Set up the project as a controlled QS exercise.

Start with a hypothetical G+2 residential building training brief. Establish project ID, document register, drawing/specification references, revision status, assumptions and query log. The project is a simulation and must not be represented as a real client project.

🏗️ REQUIRED OUTPUT

Create the Project Cover, Document Register, Assumption Register and Query/RFI Log.

PROJECT STAGE 02

Drawing Review & Scope Breakdown

STAGE OBJECTIVE

Review project information before measuring.

Apply Level 2 and Level 5 skills: check drawing identity, revisions, units, grids, levels, schedules, layers/references where applicable, and break the work into measurable sections. Record missing or conflicting information rather than guessing.

🏗️ REQUIRED OUTPUT

Prepare a drawing-review checklist and Work Breakdown Structure for the training building.

PROJECT STAGE 03

Quantity Take-Off Package

STAGE OBJECTIVE

Produce traceable measurements for the project.

Use Level 3 methods to measure selected earthwork, concrete, formwork, reinforcement-training quantities, masonry, finishes and openings. Every measurement should retain source/location references and units.

🏗️ REQUIRED OUTPUT

Prepare a take-off covering at least 20 measurable items with references and check notes.

PROJECT STAGE 04

Excel Measurement Workbook

STAGE OBJECTIVE

Build the project's connected measurement system.

Use Level 4 skills to structure inputs, take-off, checks and summaries. Use formulas rather than retyping calculated totals. Add clear units, source references and QA flags.

🏗️ REQUIRED OUTPUT

Create the project measurement workbook and verify that changing an input updates linked calculations.

PROJECT STAGE 05

CAD Measurement Verification

STAGE OBJECTIVE

Cross-check selected measurements using CAD workflow.

Apply Level 5 principles: verify units, use exact snaps, inspect layers, measure lengths/areas and document the measurement basis. Use a working copy and distinguish QS-created geometry from design information.

🏗️ REQUIRED OUTPUT

CAD-check at least five lengths and three areas and record the comparison with manual/Excel take-off.

PROJECT STAGE 06

BOQ & Estimate

STAGE OBJECTIVE

Convert project quantities into a structured training estimate.

Apply Level 6 skills: descriptions, units, work sections, quantity links, controlled training rates, amounts, section summaries and reconciliation. Pricing inputs must be sourced/dated or explicitly labelled illustrative.

🏗️ REQUIRED OUTPUT

Create a minimum 20-item BOQ and estimate with a rate-source register and summary.

PROJECT STAGE 07

Rate Analysis Package

STAGE OBJECTIVE

Build auditable rates for selected BOQ items.

Apply Level 7 skills to separate material, labour, plant and defined additions. Record assumptions, productivity basis and source dates. Do not claim hypothetical inputs are market-standard rates.

🏗️ REQUIRED OUTPUT

Prepare at least five complete unit-rate analyses linked to BOQ items.

PROJECT STAGE 08

Monthly Valuation & Cost Control

STAGE OBJECTIVE

Simulate one reporting cycle.

Apply Level 8 skills: previous/current/cumulative quantities, supporting records, change register, cost view, payment tracker, variance note and QA. Keep contractual concepts generic unless a specific training contract is provided.

🏗️ REQUIRED OUTPUT

Prepare one simulated monthly valuation and cost-control report for the project.

PROJECT STAGE 09

Portfolio Case Study

STAGE OBJECTIVE

Turn technical work into credible portfolio evidence.

A portfolio should explain the problem, your role, process, tools, deliverables, checks and learning. Clearly label the project as an academy simulation. Never imply employment/client experience you did not have.

🏗️ REQUIRED OUTPUT

Prepare a concise case study with screenshots/tables from your own work and a skills-evidence matrix.

PROJECT STAGE 10

Final Project Review & Handover

STAGE OBJECTIVE

Audit the complete project before Level 10.

Perform final checks for document control, measurement traceability, units, formulas, rate sources, BOQ reconciliation, change status, summaries and presentation. Package files logically so another reviewer can navigate them.

🏗️ REQUIRED OUTPUT

Submit the final portfolio package, self-review checklist and a short presentation explaining your QS workflow.

PROJECT GATE

Level 9 Final Review

Target: 4/5 plus all ten project stages completed. This is a readiness check, not a professional certification.
