BEFORE GOOGLE INDEXING
1. Deploy this folder to a public host.
2. Select the final public domain.
3. Replace YOUR-DOMAIN in sitemap-template.xml and rename it sitemap.xml.
4. Add the final sitemap URL to robots.txt and canonical URLs to pages.
5. Verify the site in Google Search Console and submit the sitemap/request indexing.
Google controls indexing and ranking; appearance in search is not guaranteed or immediate.
