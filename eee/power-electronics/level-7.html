Control & Feedback

Understand how a power converter maintains its desired output despite input and load changes. Study open-loop and closed-loop control, error signals, PI control, PWM, stability and a guided simulation exercise. Estimated study time: 55–75 minutes.

Learning objectives

  • Differentiate open-loop and closed-loop control.
  • Explain reference, feedback, error, controller and plant.
  • Interpret proportional and integral controller action.
  • Recognize overshoot, settling time, disturbance rejection and instability.
  • Plan a low-voltage simulated voltage-control experiment.

1. Why do converters need feedback?

A converter operating at a fixed duty cycle can change its output when the input voltage, load or component conditions change. In closed-loop control, a measured output is compared with a reference. A controller adjusts the command to reduce error, subject to physical limits and safe operating constraints.

Open-loop

A command is applied without using measured output to correct it. Simple, but it does not automatically compensate for disturbances or model mismatch.

Closed-loop

Output measurement is fed back and compared with the desired reference. Properly designed feedback can improve regulation and disturbance rejection.

Controller and plant

The controller generates a command, such as PWM duty cycle. The plant is the converter, filter and load whose behavior the controller influences.

2. Feedback signal flow

A basic voltage-regulation loop follows this sequence:

Reference → Error → Controller → PWM → Converter → Output

The measured output returns to the comparison point through the sensing path. With unity feedback:

e(t) = Vref(t) − Vmeasured(t)

Example: if the reference is 12 V and the measured output is 11.5 V, the error is +0.5 V. The appropriate duty-cycle response depends on the topology, control design and limits; the error alone is not a universal gate command.

3. Proportional and integral control

A proportional controller responds to present error. Integral action accumulates error over time and can reduce steady-state offset when the closed-loop system is appropriately designed.

u(t) = Kp e(t) + Ki ∫e(t)dt

This is the continuous-time ideal PI law. A practical digital implementation uses sampled measurements, numerical integration, output limits and anti-windup measures. Gains must be chosen for the particular plant, sampling interval and feedback scaling.

Illustrative P-only calculation: with Kp = 0.2 per volt and e = 0.5 V, the proportional contribution is 0.1 in the defined command units. This is not automatically a safe or complete duty-cycle command.

4. Dynamics and stability

Rise time describes how quickly the output initially approaches a target. Overshoot is the extent to which it exceeds the target during a transient. Settling time describes when the response stays within a specified tolerance band. Steady-state error is the remaining difference after transients settle.

Increasing controller gain does not always improve performance: excessive gain, delay or poor compensation can create oscillation or instability. Switching converters may have non-minimum-phase behavior depending on topology and operating mode; use an appropriate model and stability analysis rather than assuming one set of PI gains works everywhere.

5. PWM command limits and protection

A voltage controller may request a duty cycle, but the implementation must constrain it to a valid operating range and respect minimum on/off times, current limits, device ratings and fault handling. A PI integrator can continue accumulating error while the command is saturated, a problem called integrator windup. Anti-windup logic helps limit this effect.

Feedback sensing also needs appropriate scaling, filtering, isolation where required and fault detection. A missing or incorrect sensor signal can cause unsafe commands if not handled explicitly.

6. Worked examples

Example A: voltage error

Reference = 15 V, measured output = 14.2 V. Error = +0.8 V.

Example B: proportional action

With Kp = 0.25 per volt and error = 0.8 V, proportional contribution = 0.20 command units.

Example C: steady-state error

Reference = 10 V and settled measured output = 9.8 V. Error = 0.2 V, or 2% of the reference.

7. Guided simulation mini-project

Closed-loop buck voltage regulation

  1. In a suitable simulator, start with an idealized, low-voltage buck model: 24 V input, target 12 V output, inductor, capacitor and resistive load.
  2. Measure the output and subtract it from a 12 V reference.
  3. Use a properly scaled PI controller to produce a bounded duty-cycle request for the PWM generator. Start with conservative controller parameters and appropriate simulation settings.
  4. Compare open-loop and closed-loop responses after a modest load change. Record output deviation, overshoot, settling behavior and final error.
  5. Observe duty-cycle saturation and, if modeled, anti-windup behavior. Explain how the results depend on component and controller values.

For a starting ideal steady-state buck estimate, D ≈ 12/24 = 0.5. This estimate is not a substitute for controller tuning or protection design.

8. Safety and practice

Use simulation first. Incorrect control-loop tuning can drive real power hardware into excessive voltage or current. Do not test experimental mains-connected or high-energy converters without qualified supervision, protection and appropriate measurement equipment.
