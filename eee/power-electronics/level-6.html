MATLAB & Simulink Practice

Apply power-electronics fundamentals through numerical calculations and guided simulation workflows. This lesson uses MATLAB-style scripts and Simulink block-diagram concepts; no MATLAB licence or embedded simulator is provided by this webpage. Estimated study time: 55–75 minutes.

Learning objectives

  • Calculate ideal buck and boost converter operating points in MATLAB.
  • Identify key Simulink model elements and simulation settings.
  • Measure steady-state output voltage, current ripple and efficiency from results.
  • Recognize when simulation assumptions differ from real hardware.

1. Why simulate converters?

Simulation lets engineers test hypotheses, compare topologies and inspect voltage/current waveforms before building hardware. A model is only as accurate as its component values, device models, control logic and solver settings. Always document assumptions and check units.

2. MATLAB fundamentals: duty-cycle calculations

The following illustrative MATLAB script calculates ideal continuous-conduction-mode (CCM) buck and boost outputs for a range of duty cycles. Copy it into your own MATLAB environment if available.

% Ideal CCM buck and boost relationships
Vin = 24;                 % input voltage (V)
D = [0.2 0.4 0.6 0.8];    % duty cycles
Vbuck = D .* Vin;
Vboost = Vin ./ (1 - D);
T = table(D.', Vbuck.', Vboost.', ...
    'VariableNames', {'Duty','Buck_V','Boost_V'});
disp(T);

Expected ideal buck outputs: 4.8, 9.6, 14.4, 19.2 V. Expected ideal boost outputs: 30, 40, 60, 120 V. The last boost value is a mathematical idealization, not a practical design target.

3. Simulink model planning: a buck converter

Sketch a block-level model with a 24 V DC source, controlled switching element, freewheeling path or synchronous switch, inductor, output capacitor, resistive load and PWM/control signal. Include voltage and current measurements, a scope or data logger, and appropriate electrical reference/solver configuration for the installed block library.

  1. Start with a low-voltage idealized model and choose an appropriate switching frequency and component values.
  2. Set a 40% duty cycle and compare the steady-state average output with the ideal 9.6 V reference.
  3. Observe the inductor current and output voltage during startup and after settling.
  4. Change duty cycle and load separately; record differences between expected and simulated values.
  5. If using Simscape Electrical, follow that library's required electrical reference, solver configuration and component connection rules. Exact block names vary by release and product.

Use a time step/solver configuration fine enough to resolve switching transitions and ripple. Check that the simulation has reached steady state before comparing averages.

4. Numerical ripple estimate

For an ideal buck converter in CCM, a first-order estimate of peak-to-peak inductor current ripple is:

ΔIL ≈ (Vin − Vout) × D / (L × fs)

Example: Vin = 24 V, D = 0.5, ideal Vout = 12 V, L = 100 μH and fs = 100 kHz. Then ΔIL ≈ (24 − 12) × 0.5 / (0.0001 × 100000) = 0.6 A peak-to-peak.

Vin = 24; D = 0.5; L = 100e-6; fs = 100e3;
Vout = D * Vin;
deltaIL = (Vin - Vout) * D / (L * fs);
fprintf('Ideal Vout: %.2f V; ripple: %.2f A pp\n', Vout, deltaIL);

This estimate assumes ideal steady-state CCM; actual ripple depends on topology, component tolerances, operating mode and losses.

5. Reading results and calculating efficiency

Compare input and output power using consistently averaged measurements over the same steady-state interval. For a DC input and resistive DC output with negligible ripple, approximate Pin ≈ Vin × Iin,avg and Pout ≈ Vout × Iout,avg. For appreciable ripple, average the instantaneous product v(t)i(t) instead of blindly multiplying separate averages.

η = Pout / Pin × 100%

Example: measured Pin = 30 W and Pout = 27 W imply 90% efficiency. Ideal lossless models can report 100%; real converter losses require nonideal device and component models.
